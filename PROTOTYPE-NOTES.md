# StyleMitra Professional Fashion Studio — Prototype v3

## Phone-only first test
1. Download `stylemitra-professional-v3.zip` to your Android phone.
2. Extract the ZIP using Files / My Files.
3. Open `index.html` in Chrome. If your file manager opens it as text, use the file manager's Open with > Chrome option.
4. Try the Models, Inspiration, Model Studio, and My Studio tabs.

## Included prototype interactions
- Searchable selectable model gallery: women, curvy figures, men, and children.
- Sketch / Realistic mode interface toggle.
- Model-style settings for skin tone, hair, pose and makeup.
- Outfit options, fabric, colours, patterns and embellishment settings.
- Inspiration gallery, save-to-studio, and a generated design brief.
- Mobile-first interface for trying on an Android phone.

## Important limitations
This is a clickable UI prototype, not yet a finished fashion-design engine. The reference illustrations are raster images. Model settings are recorded in the design configuration but do not yet repaint the pixels of the reference model; outfit choices do not yet create true editable garment layers or physically drape fabric. The Realistic mode is a mode concept, not a connected AI renderer. The AI design brief creates a prompt for a future secure generation service; it does not generate an image. No API key is included.

## Next engineering milestone
Use separately licensed transparent model assets and editable garment layers (or a suitable pose-aware rendering pipeline), then implement real visual updates for skin/hair/pose and individual clothing pieces before connecting a secure AI image-generation backend.
